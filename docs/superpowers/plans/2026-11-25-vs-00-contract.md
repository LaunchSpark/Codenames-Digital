# VS Mode — Shared Contract (Track A ↔ Track B)

**Spec:** [docs/superpowers/specs/2026-11-25-lan-vs-mode-design.md](../specs/2026-11-25-lan-vs-mode-design.md)

This is the one file both tracks build against. **Track A, Task 1** commits it
verbatim as `src/shared/protocol.ts` and merges it to `main` first (it is tiny).
Track B may copy it verbatim into its branch on day one rather than wait; the
copies are identical, so the merge is a no-op.

Changing this file after both tracks start requires agreement from both people
and an edit to this document.

## Transport

- One WebSocket per device at path **`/ws`** on the same host and port that
  served the page (`ws://${location.host}/ws`).
- Every frame is one JSON object: client → server is a `ClientMessage`,
  server → client is a `ServerMessage`.
- On every (re)connect the client's **first** message is `hello`.
- The server answers every accepted message by broadcasting a fresh `state` to
  **every** connected device (each with its own filtered view). Rejected
  messages get an `error` to the sender only, and no state change.
- Host = a connection whose real client address is loopback (see Track A).
  Host actions from non-host connections are rejected with `not-host`.

## Seat identity

- Server issues a seat token in `welcome` after a successful `join`.
- Client stores it in `localStorage` under **`codenames-seat`** and sends it in
  every `hello`.
- If the server doesn't know the token (e.g. it restarted), it treats the device
  as unjoined (`you.kind === 'spectator'`). The client then deletes the stored
  token and shows the join screen.

## `src/shared/protocol.ts`

```ts
export type Team = 'red' | 'blue'
export type CardColor = Team | 'neutral' | 'assassin'
export type Mode = 'vs' | 'coop'

export interface PlayerInfo {
  id: string
  name: string
  team: Team
  connected: boolean
}

export interface Clue {
  team: Team
  word: string
  /** 1–9. */
  number: number
}

export type Phase =
  | { name: 'lobby' }
  | { name: 'clue'; team: Team }
  | {
      name: 'guess'
      team: Team
      clue: Clue
      /** Starts at clue.number + 1. */
      guessesLeft: number
      /** Reveals made this turn; end-turn voting needs >= 1. */
      guessesMade: number
    }
  | { name: 'over'; winner: Team; reason: 'cards' | 'assassin' }

export interface CardView {
  word: string
  revealed: boolean
  /**
   * The card's colour if this viewer may know it: always when revealed; for an
   * unrevealed card ONLY in a current clue-giver's view or once phase is
   * 'over'. Otherwise null. The server enforces this — never the client.
   */
  color: CardColor | null
  /** Guessers on the active team currently voting for this card (pips filled). */
  votes: number
}

export interface TeamView {
  team: Team
  /** In clue-giver rotation order. */
  players: PlayerInfo[]
  /** Current game's clue-giver; null in lobby or when the host must pick one. */
  clueGiverId: string | null
  /** Unrevealed cards of this colour; null in lobby. */
  remaining: number | null
}

export interface GameView {
  mode: Mode
  phase: Phase
  /** 25 cards, row-major; null in lobby. */
  board: CardView[] | null
  teams: Record<Team, TeamView>
  /** Team owning 9 cards and going first; null in lobby. */
  startingTeam: Team | null
  /** All clues this game, oldest first. */
  clues: Clue[]
  /** Pip slots per card = connected guessers on the guessing team (0 outside 'guess'). */
  voterCount: number
  /** Guessers currently voting to end the turn. */
  endTurnVotes: number
  /** True when there is a move to undo. */
  canUndo: boolean
  /** e.g. "http://192.168.1.20:3000/" — what the TV's QR code encodes. */
  joinUrl: string
}

export type You =
  | { kind: 'tv'; host: boolean }
  | { kind: 'spectator' }
  | {
      kind: 'player'
      id: string
      team: Team
      /** null in lobby. */
      role: 'clue-giver' | 'guesser' | null
      /** This player's own current vote. */
      vote: number | 'end' | null
    }

export type ErrorCode =
  | 'not-host'
  | 'bad-message'
  | 'name-invalid'
  | 'name-taken'
  | 'not-in-lobby'
  | 'not-enough-players'
  | 'not-your-turn'
  | 'invalid-clue'
  | 'invalid-vote'
  | 'nothing-to-undo'
  | 'unknown-player'

export type ServerMessage =
  | { type: 'welcome'; token: string; playerId: string }
  | { type: 'state'; view: GameView; you: You }
  | { type: 'error'; code: ErrorCode; message: string }

export type ClientMessage =
  | { type: 'hello'; client: 'tv' }
  | { type: 'hello'; client: 'player'; token: string | null }
  /** Join (first time, lobby or mid-game) or, in lobby only, switch team. */
  | { type: 'join'; name: string; team: Team }
  /** Active clue-giver, during their team's 'clue' phase. */
  | { type: 'clue'; word: string; number: number }
  /** Guesser on the guessing team. Same card again clears the vote. */
  | { type: 'vote'; card: number }
  /** Guesser; toggles their end-turn vote. Needs guessesMade >= 1. */
  | { type: 'vote-end' }
  /** Either current clue-giver. */
  | { type: 'undo' }
  | { type: 'host:start' }
  | { type: 'host:new-game' }
  | { type: 'host:lobby' }
  | { type: 'host:make-clue-giver'; playerId: string }
  | { type: 'host:skip-turn' }
  | { type: 'host:remove-player'; playerId: string }

export const SEAT_STORAGE_KEY = 'codenames-seat'
export const WS_PATH = '/ws'
export const BOARD_CELLS = 25
```

## Semantics both sides rely on

- `join` while already seated and in lobby = rename/switch team (appends to the
  end of the new team's list). Mid-game, a seated player's `join` is rejected
  `not-in-lobby`; an unseated device's `join` mid-game seats them as a guesser.
- Names: trimmed, 1–20 characters, unique case-insensitively (`name-invalid`,
  `name-taken`). A seated player keeping their own name is not "taken".
- `host:start` needs ≥ 2 players on each team (`not-enough-players`).
- `host:new-game` is valid from 'over' (and 'clue'/'guess', abandoning the
  current game); `host:lobby` from any non-lobby phase.
- When `clueGiverId` is null mid-game, the TV host menu should prompt the host
  to pick one (`host:make-clue-giver`).
